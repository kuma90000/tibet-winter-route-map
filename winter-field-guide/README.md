# 西藏冬季旅行 · 行程与摄影手册

一个无构建步骤、无后端的静态网站：2026年12月24日至2027年1月3日（11天10晚）的工作行程，包含逐日安排、摄影建议、备选路线与12张交互地图。

## 本地运行

需要 Python 3。在本仓库根目录执行：

```sh
python3 -m http.server 8000 --directory site
```

打开 `http://localhost:8000/`。没有 npm 安装或构建步骤。D3 7.9.0 已本地保存，图片和地图不依赖外部 CDN；参考资料链接需要网络。

## 文件与编辑

- `site/index.html`：完整内容与结构（251个源内容块、45张表，按章节与日期导航）。
- `site/style.css`：桌面和手机样式。
- `site/app.js`：章节导航、搜索、日程和表格展开。
- `site/assets/asset_*.html`：12张交互地图，包含路线/点位数据与地图绘制代码。
- `site/assets/asset_*.jpg` 等：30张原文参考照片。
- `site/assets/d3.min.js`：D3 7.9.0（源文件头保留许可证声明）。

直接编辑以上文件并刷新浏览器。`site/` 本身就是完整部署目录，不需要原始导出环境或私有路径。

## 静态托管

将 `site/` 目录作为发布根目录上传到任意静态托管平台即可，首页为 `index.html`。如托管配置要求构建命令，留空；输出目录填写 `site`。仓库私有不代表托管后的网站私有，请单独确认托管平台的访问控制。

本次迁移不启用 GitHub Pages，不更改原 Site 的访问权限，不包含部署凭据、内部Git配置或环境变量。
