## 本地运行与编辑

解压source-package.zip，在项目根目录运行 `python3 本地启动器.py`，或直接打开独立HTML。修改源码后运行 `python3 源码/build.py`；数据校验为 `python3 源码/validate_data.py`。运行仅需Python标准库。

原地图功能保留：路线/日期切换、逐日图文、地点详情、相册、驾驶时长图、海拔参考、叠加对比、CSV与URL状态。新路线支持7天或12天，未知海拔不填0。
