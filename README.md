# 西藏路线地图 · 图文版

[打开交互地图](https://kuma90000.github.io/tibet-winter-route-map/) · [下载完整源码包](https://kuma90000.github.io/tibet-winter-route-map/source-package.zip)

以「添加稻草人线路」会话的最新版为基础：7条自拟路线 + 7条稻草人线路，共14条、92个地点。原有路线数据未改动；自拟方案按日阅读，稻草人按原线主要路段阅读，编号不代表官方第几天，不含团期。

右侧「图文」页签包含景观介绍、亮点图片和注意事项。点击地图点可打开完整地点介绍，并跳转到相关路线。2026-10-03进一步查阅地方文旅、政府、UNESCO和科研资料，丰富49个重点地点的背景、看点、观景与摄影建议，并在详情附资料链接与查阅日期。观景与摄影建议为编辑整理。

44张Wikimedia Commons授权图片已内置，14个地点支持多图切换，图注、作者、原图及许可链接同步更新。地面实景、太空／卫星影像和周边参考图逐图标明；暂无对应可复用实景的地点使用明确标示的位置示意。图像已缩小、压缩，展示可能裁切，继续依对应原许可分发。

默认OpenStreetMap，无需Key；断网可使用离线示意地图。保留逐日路线、图例、叠加比较、海拔和驾驶时间图表、CSV导出；高德/百度仅在用户填写自己的Key并启用后加载官方SDK。

本地图为经由点连线示意，非导航轨迹。行车时间、海拔和里程为原有规划参考；照片不保证当日景色。开放、道路、边境手续与冰川允许区域需临行核实。

## 修改内容

解压源码包，编辑 `源码/地点图文与照片.json`，可修改简介、背景、看点、观景建议、提示、来源和相册信息；`源码/地点资料来源.json`为资料台账。再运行 `python3 源码/build.py` 生成独立HTML。路线数据、页面、样式和脚本亦已拆分。照片保持各自许可，不扩展至独立代码与路线数据。
