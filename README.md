# 藏行 · 西藏冬季路线地图

7条西藏冬季路线的交互比较网页。默认使用无需Key的OpenStreetMap底图，保留逐日路线、highlights图例、住宿海拔、海拔变化、行车时间、路线对比和CSV导出。

网页入口是 `index.html`，GitHub Pages从 `main` 分支根目录发布。

高德和百度仅在用户填写自己的Key并主动启用后加载官方服务；Key不会写入仓库。高德/百度的额度、计费及域名授权由各自账号控制台管理。无网络或底图不可用时回退到离线示意图。

[source-package.zip](./source-package.zip) 包含原始路线数据、可重建源码、本地启动器、使用说明和7份逐日CSV。

地图仍是经由点连线示意，不是贴合真实公路的导航轨迹。里程、时间及海拔都是规划参考值；景区开放与冬季交通情况需临近出发核实。
