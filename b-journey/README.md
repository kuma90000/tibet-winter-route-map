无构建依赖。数据和来源在 `data.js`，住宿信息在 `stays.json`，照片与逐图许可在 `assets/photos.json`。行程时间、海拔为近似规划值；照片为真实历史景观，不能代表实时天气、冰况、房态或通行状态。

所有照片遵循各自许可，许可不扩展到独立行程内容或代码。
