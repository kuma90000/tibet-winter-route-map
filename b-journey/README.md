## 文件与验证

无构建依赖，当前目录即静态网站。数据在 `data.js`，住宿在 `stays.json`，照片许可在 `assets/photos.json`。保留景点资料、地图、海拔图、天气机动选项与本机清单功能。

本机清单和备忘仅保存在浏览器，分享链接不含备忘。主动复制、下载、打印会包括本机备忘，分享前请自行检查。

在本目录运行 `python3 -m http.server 4175` 后，打开 `http://localhost:4175/` 预览。GitHub Pages 随 main 分支更新发布。

照片遵循各自许可，许可不扩展到独立内容或代码。
